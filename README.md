# 학습부 안내 사이트 — 수정 설명서

사이트 주소: **https://yeosugo.github.io**

이 문서는 학습부 부원이 시험범위와 수행평가 일정을 직접 고치기 위한 설명서입니다.
코딩 몰라도 됩니다. 정해진 칸에 글자만 바꾸면 됩니다.

---

## 0. 시작 전에

- 수정 권한은 **초대받은 부원**만 있습니다. 초대가 안 왔으면 부장에게 말하세요.
- 이 저장소는 **공개(Public)** 입니다. 인터넷 아무나 볼 수 있습니다.
  - 학생 이름·연락처, 선생님 연락처, 시험지 사진은 **절대 올리지 마세요.**
- 뭘 잘못 고쳐도 기록이 다 남아서 되돌릴 수 있습니다. 겁내지 말고 고치세요.
  복구 방법은 이 문서 맨 아래에 있습니다.

---

## 1. 담당 나누기

각자 자기 학년 칸만 고칩니다. 남의 학년은 건드리지 않습니다.

| 학년 | 담당 | 비고 |
|---|---|---|
| 1학년 | | |
| 2학년 | | |
| 3학년 | | |

> 이 표는 담당이 정해지면 채우세요. 공개 페이지이므로 **실명 대신 학년·반 정도만** 적는 걸 권합니다.

---

## 2. 수정 화면 들어가기

1. 이 저장소에서 **`index.html`** 파일을 클릭
2. 오른쪽 위 **연필 아이콘**(Edit this file) 클릭
3. `Ctrl + F`(맥은 `Cmd + F`)로 찾고 싶은 단어 검색
   - 수행평가 고칠 때 → `수행:` 검색
   - 시험범위 고칠 때 → `과목:` 검색
   - 자기 학년 찾을 때 → `───── 2학년 ─────` 같은 줄 검색
4. 다 고쳤으면 오른쪽 위 초록색 **Commit changes** → 팝업에서 한 번 더 **Commit changes**
5. 약 1분 뒤 사이트에 반영됩니다. 새로고침해서 확인하세요.

폰으로도 됩니다. 브라우저에서 github.com 접속해서 똑같이 하면 됩니다.

---

## 3. 수행평가 고치기

`수행: [` 부분을 찾으세요. 이렇게 생겼습니다.

```javascript
수행: [
  { 과목:"화학Ⅰ", 내용:"탐구 보고서 제출", 날짜:"2026-09-19", 계열:"자연" },
  { 과목:"영어Ⅱ", 내용:"영어 에세이 작성", 날짜:"2026-09-24", 계열:"공통" }
]
```

### 새로 추가할 때

줄 하나를 통째로 복사해서 아래에 붙여넣고 내용만 바꾸세요.

```javascript
  { 과목:"세계사", 내용:"모둠 발표", 날짜:"2026-10-20", 계열:"인문" },
```

### 날짜가 바뀌었을 때

`날짜:"2026-09-19"` 안의 숫자만 고치면 됩니다. D-day는 자동으로 다시 계산됩니다.

### 없어졌을 때

그 줄 전체를 지우세요. 지운 뒤 앞뒤 줄의 쉼표가 규칙(아래 5번)에 맞는지 확인하세요.

---

## 4. 시험범위 고치기

`과목: [` 부분을 찾으세요.

```javascript
{ 과목:"물리학Ⅰ", 계열:"자연", 범위:"역학적 에너지 ~ 열역학 제2법칙",
  비고:"공문서상 범위와 차이가 있어 확인 중", 상태:"확인중" },
```

### 범위가 확정됐을 때

`상태:"확인중"` → `상태:"확정"` 으로 바꾸고,
`비고:"..."` → `비고:""` 로 비우면 분홍색 경고 문구가 사라집니다.

### 아직 확인 중일 때

`상태:"확인중"` 으로 두고, `비고:` 에 **무엇이 왜 불확실한지** 적으세요.

좋은 예: `비고:"수업에서는 열역학까지 안내됨. 공문서와 달라 담당 선생님께 확인 요청함."`
나쁜 예: `비고:"확인중"` ← 아무 정보가 없습니다.

> **중요**: 확실하지 않으면 `확정`으로 올리지 마세요.
> 틀린 범위를 확정으로 올리는 게 비워두는 것보다 훨씬 큰 사고입니다.

---

## 5. 안 깨지게 지킬 규칙 4개

| 규칙 | 잘못된 예 | 맞는 예 |
|---|---|---|
| 날짜는 항상 네자리-두자리-두자리 | `2026-9-5` | `2026-09-05` |
| 내용은 큰따옴표 안에 | `과목:화학Ⅰ` | `과목:"화학Ⅰ"` |
| 줄 끝에 쉼표, 맨 마지막 줄만 없음 | 중간 줄에 `}` | 중간은 `},` 마지막은 `}` |
| 계열·상태는 정해진 단어만 | `계열:"이과"` | `계열:"자연"` |

- **계열**에 쓸 수 있는 단어: `공통` `인문` `자연`
  - `공통`은 모든 학생에게 보입니다. 계열 상관없는 과목은 전부 `공통`.
- **상태**에 쓸 수 있는 단어: `확정` `확인중`

다른 단어를 쓰면 오류는 안 나지만 필터에서 안 잡혀서 **학생들 화면에 안 보입니다.**

### 큰따옴표 안에 큰따옴표 쓰지 마세요

```javascript
내용:"교과서 "3단원" 발표"   ← 사이트 깨짐
내용:"교과서 3단원 발표"      ← 이렇게
```

## 6. 절대 건드리면 안 되는 곳

파일 중간에 이런 줄이 있습니다.

```
■ 프로그램 영역 — 수정하지 마세요 ■
```

**이 줄 아래쪽은 화면을 그리는 코드입니다.** 손대면 사이트 전체가 하얗게 뜹니다.
고칠 내용은 전부 이 줄 **위쪽**에 있습니다.

맨 위 `설정` 부분(학교 이름, 업데이트 날짜, 기본 학년, 제보 폼 주소)은 부장만 고칩니다.

---

## 7. 고친 뒤 꼭 할 일

1. **사이트 직접 열어서 확인하기.** Commit만 하고 안 보는 게 제일 흔한 실수입니다.
2. 화면이 **하얗게 비어 있으면 깨진 것**입니다. 바로 8번으로 가세요.
3. 파일 맨 위 `업데이트: "2026-09-13"` 을 오늘 날짜로 바꾸세요.
   학생들이 이 날짜를 보고 정보가 최신인지 판단합니다.

---

## 8. 사이트가 하얗게 떴을 때 (복구)

당황하지 말고 순서대로 하세요. 1분이면 됩니다.

1. 저장소 위쪽 **Commits**(시계 모양 아이콘) 클릭
2. 목록에서 **멀쩡했던 시점**을 클릭 (보통 바로 위 항목)
3. `index.html` 클릭 → 오른쪽 위 **···** → **View file**
4. 내용 전체 선택해서 복사
5. 현재 `index.html` 편집 화면으로 가서 전체 지우고 붙여넣기 → Commit

그래도 안 되면 부장에게 말하세요. 혼자 붙잡고 있지 마세요.

---

## 9. 학생 제보가 들어왔을 때

사이트 아래 "다른 점 알리기" 버튼으로 들어온 내용 처리 순서입니다.

1. **바로 고치지 않습니다.** 제보는 제보일 뿐 사실 확인 전입니다.
2. 해당 과목 상태를 **`확인중`** 으로 바꾸고, 비고에 상황을 적습니다.
3. 담당 선생님께 직접 확인합니다.
4. 확인되면 범위를 수정하고 상태를 `확정`으로 되돌립니다.
5. 제보자가 이름을 남겼으면 결과를 알려줍니다.

**제보자 이름은 사이트에 절대 올리지 마세요.** 비고에도 쓰지 않습니다.

## 10. 자주 나오는 질문

**Q. 실수로 남의 학년을 고쳤어요**
→ 8번 복구 절차대로 되돌리고, 해당 학년 담당자에게 알려주세요.

**Q. 두 명이 동시에 고치면요?**
→ 나중에 저장하는 사람에게 경고가 뜹니다. 그때는 저장하지 말고 새로고침한 다음 다시 고치세요.
→ 애초에 같은 학년을 둘이 만지지 않는 게 제일 좋습니다.

**Q. 링크를 어디에 뿌려요?**
| 대상 | 주소 |
|---|---|
| 전체 | https://yeosugo.github.io |
| 1학년 | https://yeosugo.github.io/#1학년 |
| 2학년 | https://yeosugo.github.io/#2학년 |
| 3학년 | https://yeosugo.github.io/#3학년 |

**Q. 시험 끝난 뒤에는요?**
→ 지난 수행평가는 자동으로 흐리게 처리되니 굳이 지우지 않아도 됩니다.
→ 다음 지필평가가 잡히면 `지필:` 의 이름과 날짜를 바꾸고 범위를 새로 채우세요.
